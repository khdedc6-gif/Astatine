# Overview Page Overrides

> **Project:** Astatine
> **Page type:** Learning dashboard

Continue the Master claymorphism system through the overview hero and its
note-and-pencil illustration. Keep the current responsive hero composition and
retain the built-in illustration as the fallback when no custom image is set
or the image cannot load.

The admin-uploaded overview image replaces only the illustration artwork; it
must not obscure the greeting, calls to action, or dashboard navigation.
