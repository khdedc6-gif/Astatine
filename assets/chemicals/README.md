# Chemistry assets

This folder stores placeholder solid-state illustrations for reagents used in the virtual chemistry lab.

These SVG files are intentionally simple placeholders so the app can reference them immediately. Replace any file with a cleaned PNG/SVG matching the real material appearance.

Recommended naming:
- Use lowercase names with underscores, for example `na.svg`, `k.svg`, `cu_oh_2.svg`.
- Keep transparent backgrounds and a square canvas.
- Preferred size: 512x512 for clean scaling.
